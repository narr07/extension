# Extension

Kumpulan extension browser untuk Microsoft Edge dan Google Chrome (Manifest V3). Setiap extension ada di foldernya sendiri dan bisa dipasang atau dikemas secara terpisah.

| Extension | Kegunaan |
| --- | --- |
| [input-kib-e](input-kib-e/) | Input data aset KIB-E (Aset Tetap Lainnya) di asetdisdik.id secara massal dari invoice PDF SIPLah, Excel, atau CSV |

## Memasang extension dari repo ini

1. Clone atau unduh repo ini.
2. Buka `edge://extensions` (Edge) atau `chrome://extensions` (Chrome), lalu aktifkan **Developer mode**.
3. Klik **Load unpacked** dan pilih folder extension yang diinginkan, misalnya `input-kib-e/`.

Panduan pemakaian dan cara menerbitkan ke store ada di README masing-masing extension.
